# 第三方元件授權 / Third-party notices

OpenDRS {version} 的 Rust 版是靜態連結的執行檔，內含多個 Rust 套件（crates.io）。
每個套件的名稱、版本、授權與授權全文列在同一資料夾的 `THIRD_PARTY_LICENSES.txt`，
由 `cargo xtask dist` 從實際編入這個平台執行檔的套件產生。

執行時會使用、但不隨附的系統元件：作業系統的字型、繪圖驅動程式（經由 wgpu）、憑證庫、
Linux 的 libudev；匯出 PDF 時呼叫使用者已安裝的 Microsoft Edge 或 Google Chrome。

本程式不隨附、也不重製原廠的 `IAP+Flash.exe`、`Wav.exe`、`ambep2.exe`（DVSI）或任何原廠韌體；
需要時由使用者自行指定其位置。

The Rust build of OpenDRS is a statically linked executable built from the crates listed, with
their licence texts, in `THIRD_PARTY_LICENSES.txt` (generated by `cargo xtask dist` from the
crates actually compiled for this platform). System fonts, GPU drivers, the certificate store,
libudev (Linux) and an installed Edge or Chrome (PDF export) are used but not included. Vendor
tools (IAP+Flash.exe, Wav.exe, DVSI ambep2.exe) and vendor firmware are not included.
